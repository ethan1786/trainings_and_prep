Four Golden Signals (Google SRE)

1. Latencyp50, p99, p99.9
2. TrafficQPS — detect spikes/drops
3. Errors5xx rate, error ratio
4. SaturationCPU, memory, connections, disk

Deployment

  • Canary: 1-5% traffic → watch metrics → full rollout
  • Blue-green: instant rollback, 2x resources
  • Feature flags: decouple deploy from release, kill switch

Staff+ On-Call Test

"If paged at 3AM: what dashboard do I check? What runbook do I follow? What lever can I pull?"

Financial Systems (Coinbase/Stripe) — Extra Constraints

When interviewer says "this handles money":

  • Idempotency on every write (client-generated key)
  • WAL + sync replication (zero data loss)
  • Double-entry ledger (debit + credit = balanced)
  • Reconciliation job (internal vs external provider)
  • Event sourcing for full audit trail
  • Auth-then-capture for payment holds
  • No Redis as primary store for financial data
  • Availability + Durability are FIRST-CLASS, not addons
